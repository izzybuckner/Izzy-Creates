# X3 30e Deal Finder

Static site (no build step). Open `index.html`, or serve the folder with GitHub Pages.

- `index.html` : X3 xDrive30e deal finder. The fair-price model now has a CarMax term (about +$2,359 +/- $551 from 10 CarMax cars).
- `x5.html` : 20 CarMax X5 plug-in asking prices (from app screenshots, Nov 11 2026) with a CarMax-only price model.
- `style.css` : shared styles.

Data lives in the `RAW` arrays at the top of each page's script.
